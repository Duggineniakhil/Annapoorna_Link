# Annapoorna Link — frontend (`app/`)

Mobile-first PWA for Annapoorna Link (అన్నపూర్ణ లింక్). Donors post surplus food, receivers accept offers,
volunteers pick up and deliver, and sponsors see city impact, in English and Telugu.

**Owner:** Member A. Member B owns `server/`; the frontend never edits files there.

## Stack

React 18 · Vite 5 · TypeScript (strict) · Tailwind CSS 3 · React Router 6 · vite-plugin-pwa (Workbox) ·
self-hosted Noto Sans Telugu · ESLint 9 + Prettier. No UI library.

## Run

Needs Node 20.19+ (or 22.12+).

```bash
cd app
npm install
cp .env.example .env.local   # optional; mocks are on by default
npm run dev                  # http://localhost:5173
```

| Script | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload (service worker off in dev) |
| `npm run build` | Type-check (`tsc -b`) and production build to `dist/` |
| `npm run preview` | Serve `dist/` locally; use this to test install/offline |
| `npm run lint` | ESLint |
| `npm run format` | Prettier (write) |

To open the dev server on a phone on the same Wi-Fi: `npm run dev -- --host`, then visit the printed
network URL.

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `VITE_API_BASE_URL` | empty | Backend base URL, e.g. `https://<server>.onrender.com`. Empty while using mocks. |
| `VITE_USE_MOCKS` | `true` | `true` = local mock data in `src/mocks/`; `false` = call the real API. |

These are baked in at build time and are public. Never put secrets in `VITE_*` variables.

## Languages

- Every visible string comes from `src/i18n`. Add a key to `en.ts` first; TypeScript then requires the
  same key in `te.ts`.
- `t("key", { name: "value" })` fills `{name}` placeholders. Missing Telugu falls back to English.
- The choice is saved in `localStorage` (`annapoorna.lang`) and sets `<html lang>`.
- The Telugu text is a draft and needs review by a native speaker before the demo.

## PWA

- The manifest is generated by vite-plugin-pwa (`vite.config.ts`): name "Annapoorna Link", short name
  "Annapoorna", theme `#7a3e00`, icons 192/512 (512 also maskable).
- The service worker precaches the app shell (JS, CSS, HTML, icons, woff2 fonts) so the screens open
  offline. `/api/*` is never served from the app shell.
- `registerType: "prompt"`: a new version waits until the user accepts it. The "new version available"
  banner is added in task A2.
- To test: `npm run build && npm run preview`, open Chrome DevTools → Application → Manifest /
  Service workers, then tick "Offline" and reload.

Check after each task with `npm run build` and look at the sizes printed.
